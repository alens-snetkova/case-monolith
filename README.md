# MONOLITH Case Study: Custom UI Components

Коллекция кастомных, высокопроизводительных React-компонентов, разработанных для платформы **MONOLITH** (архив и покупка билетов на выставки). 

Компоненты изначально создавались как Code Components для среды Framer, но здесь они вынесены в чистый формат **React + TypeScript**. Этот репозиторий демонстрирует умение решать сложные UI-задачи, оптимизировать рендеринг и создавать плавные, доступные интерфейсы без reliance на тяжелые сторонние библиотеки анимаций.

🔗 **[Посмотреть живой проект](https://ennyx.framer.website/case_monolith)**

## 🛠 Технологический стек

- **React** (Functional Components, Hooks)
- **TypeScript** (Строгая типизация пропсов и событий)
- **Browser APIs** (Intersection Observer, Resize Observer, RequestAnimationFrame)
- **SVG & CSS** (Аппаратное ускорение, Mobile-first адаптивность)

## 📦 Ключевые компоненты

### 1. CustomScrollbar
Кастомный вертикальный индикатор прокрутки с поддержкой drag-and-drop (мышь и тач).
- **Оптимизация:** Использование формулы линейной интерполяции (Lerp) для плавного, "вязкого" следования за скроллом без рывков.
- **Производительность:** Прямая манипуляция DOM через `useRef` внутри `requestAnimationFrame` для стабильных 60 FPS, минуя цикл ререндеров React.
- **UX:** Корректная обработка `passive: true` для скролла страницы и `passive: false` для перехвата тач-событий при драге.

### 2. CircularReveal / CircularRevealRings
Анимация посекторного появления и исчезновения круговых элементов.
- **Оптимизация:** Тяжелые математические вычисления (`Math.sin`/`Math.cos`) для генерации SVG-путей обернуты в `useMemo` и выполняются **только один раз** при монтировании.
- **Архитектура:** Использование `requestAnimationFrame` с четким разделением на фазы (задержка, сборка, пауза, сброс) для предсказуемой и плавной анимации.

### 3. CheckIconAdaptive
Адаптивная иконка "галочка" с поэтапной SVG-анимацией отрисовки.
- **Responsive:** Использование `ResizeObserver` с `Math.round` для предотвращения бесконечных циклов ререндеров из-за субпиксельных значений.
- **Производительность:** Фиксированный `viewBox="0 0 100 100"`. Браузер сам масштабирует графику через CSS, что избавляет React от дорогостоящих пересчетов координат при изменении размера окна.

### 4. Preloader
Экран загрузки с имитацией прогресса и эффектом "шторки".
- **UX:** Двухэтапная анимация завершения (пауза на "100%" для регистрации завершения пользователем, затем плавный уход вниз).
- **Доступность:** Использование `pointer-events: none` во время анимации шторки, чтобы пользователь мог начать взаимодействовать с сайтом до полного исчезновения прелоадера.

### 5. Scroll Hints (White / Black)
Подсказки "SCROLL", появляющиеся при скролле.
- **Логика:** Использование `IntersectionObserver` с флагом `hasAnimated`, чтобы анимация не дергалась, но могла перезапуститься, если пользователь вернулся к секции.
- **Безопасность:** Строгая очистка `setTimeout` и `observer.disconnect()` в `useEffect` cleanup для предотвращения утечек памяти (memory leaks).

### 6. BackToHome
Фиксированная кнопка возврата на главную.
- **Accessibility (a11y):** Использование семантического тега `<a>` вместо `<div>`, что обеспечивает корректную работу с клавиатуры (Tab/Enter) и скринридерами.
- **UX-паттерн:** Использование комбинации `padding` и отрицательного `margin` для увеличения кликабельной зоны (hit area) до рекомендуемых 48px без визуального увеличения элемента и сдвига соседней верстки.

## 🚀 Архитектурные решения и Best Practices

1. **Избегание лишних ререндеров:** Для высокочастотных обновлений (анимации, драг) используется связка `useRef` + прямая манипуляция стилями, а не `useState`.
2. **GPU-ускорение:** Стратегическое использование CSS-свойства `will-change: transform, opacity` для выноса анимируемых элементов в отдельные композитные слои браузера.
3. **Чистота кода:** Вынос неизменяемых констант и чистых функций (например, `createArcPath`) за пределы тела компонента.
4. **Мобильная адаптивность:** CSS написан по принципу Mobile-first (использование `min-width` в media queries), что обеспечивает более чистый и быстрый рендеринг.
